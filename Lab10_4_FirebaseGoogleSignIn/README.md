# Lab 10.4 — Firebase Google Sign-In

Google sign-in requires **your own Firebase project**. Before testing on an Android device:

1. Create a Firebase project, add this app's Android application ID (see `android/app/build.gradle.kts`), and enable the **Google** provider in Firebase Authentication.
2. Register both debug/release SHA-1 and SHA-256 fingerprints in Firebase; use an emulator/device with Google Play Services.
3. Run `flutterfire configure` for this project and platform, then change `Firebase.initializeApp()` in `lib/google_app.dart` to `Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform)` and import `firebase_options.dart` generated by FlutterFire. Ensure the platform's OAuth configuration (including Google web client ID if required) is present; download the refreshed `google-services.json` after adding SHA keys. Follow the current FlutterFire/Google Sign-In v7 platform setup documentation.
4. Run `flutter pub get` and `flutter run`. Tap **Sign in with Google**, verify profile/name/photo, then **Logout**.

No Firebase configuration, IDs, credentials or user account are bundled. With no configuration, the app displays setup guidance instead of pretending authentication worked. No test account: use a Google account authorized by your Firebase configuration. Run `flutter analyze` and `flutter test` for code-level checks; interactive sign-in needs a configured device.
